# Advanced Automated Backup System

A professional Python-based automated backup application with GUI, scheduling, ZIP compression, and desktop notifications.

## Features

- Automatic scheduled backups
- GUI interface using Tkinter
- ZIP compression
- Desktop notifications
- Backup logs
- Error handling
- EXE support

## Technologies Used

- Python
- Tkinter
- shutil
- zipfile
- schedule
- plyer

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python backup.py
```

## Convert to EXE

```bash
pyinstaller --onefile --windowed backup.py
```
